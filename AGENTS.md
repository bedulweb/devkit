# Agent Instructions

## Purpose

This repository bootstraps a Linux VM and restores the projects listed in
`projects.yaml`. Read this file before changing bootstrap, authentication, or
Git credential behavior.

## Fresh VM setup

`DOPPLER_TOKEN` is a required external input for private GitHub restores. It is
not generated by this repository and must be provisioned by the operator using
cloud-init, systemd, `~/.devkit.env`, or an interactive shell. Never invent,
print, commit, or request a secret value in a repository file.

The token should be a read-only Doppler service token that can read the config
containing `GITHUB_TOKEN` (defaults: `vendor-access/prd`). If that token is not
available, stop before restoring private repositories and ask the operator to
provide or provision it. Public repository setup may continue.

For a new VM, run:

```bash
export DOPPLER_TOKEN=dp.st.xxx
curl -fsSL https://raw.githubusercontent.com/bedulweb/devkit/main/bootstrap-vps.sh | bash
```

The bootstrap sequence installs Doppler, authenticates it, installs the
Doppler-backed GitHub credential helper, and then restores private projects.
The helper reads `GITHUB_TOKEN` at Git credential time; it does not put the
GitHub token in `~/.gitconfig`, a remote URL, or a credential file.

## Authentication contract

- Doppler authentication input: `DOPPLER_TOKEN`.
- GitHub token source: `GITHUB_TOKEN` or `GH_TOKEN` from the configured Doppler
  project/config.
- Defaults: `DEVKIT_GITHUB_DOPPLER_PROJECT=vendor-access` and
  `DEVKIT_GITHUB_DOPPLER_CONFIG=prd`.
- Override those defaults only when the alternate Doppler config contains the
  GitHub token and the service token can read it.
- Direct `GH_TOKEN` remains a fallback for operators who intentionally use a
  GitHub PAT.

The permanent setup entrypoint is:

```bash
bash ~/linux-devkit/scripts/install-git-credential-helper.sh
```

Verify completion without displaying secrets:

```bash
doppler whoami
git config --global --get credential.https://github.com.helper
git ls-remote https://github.com/wazapin/platform.git HEAD
```

The final command must return a commit hash. Then `git pull` must work without
an interactive username/password prompt.

## When given a repository link

If an agent receives only the GitHub URL for this repository:

1. Clone or open the repository.
2. Read this `AGENTS.md` before running setup commands.
3. Check whether `DOPPLER_TOKEN` is already available without printing it.
4. If it is absent, ask the operator to provision it; do not substitute a
   guessed token or write a token into source control.
5. Run the documented bootstrap or helper installer.
6. Verify `doppler whoami`, the configured helper path, and an authenticated
   `git ls-remote` before claiming that private-repository login works.

## Change rules

Keep GitHub authentication Doppler-backed and host-specific. Preserve the
property that GitHub tokens are never embedded in `url.*.insteadOf`, remote
URLs, logs, or committed files. After changes, run `bash -n` on modified shell
scripts, `git diff --check`, and the verification commands above.
